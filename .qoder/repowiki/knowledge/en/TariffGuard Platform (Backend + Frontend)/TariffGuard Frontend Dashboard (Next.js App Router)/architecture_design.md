Built on Next.js 16 App Router with a feature-based page layout under `app/`: `(auth)` route group for login/signup, `(marketing)` landing page, and `dashboard/` as the authenticated app shell. The root `app/layout.tsx` wraps all routes in `AuthProvider` from `context/auth_context.tsx`, which persists JWT tokens and user role in `localStorage` and exposes login/register/demo/logout actions via React context. Each dashboard subpage (`alerts`, `chat`, `cost_analysis`, `live_monitoring`, `machines`, `reports`, `schedule_optimizer`, `settings`, `tariff_calendar`) is a self-contained page component rendered inside `dashboard/layout.tsx`, which composes the shared `AppShell` (sidebar + topbar + main content area) from `components/layout`. UI is split into reusable primitives under `components/ui` (button, badge, glass_panel, kpi_card, status_dot), domain-specific charts under `components/charts` (Recharts-based cost breakdown, energy consumption, Gantt schedule), and forms under `components/forms`. Data access is centralized in `lib/api.ts`, which currently returns mock data from `lib/mock_data.ts` while exposing a real `fetchApi` helper that attaches Bearer tokens read from localStorage; typed domain models live in `types/index.ts`. Testing uses Jest with `next/jest` adapter and jsdom environment configured in `jest.config.js`.
