The application is a standard FastAPI project bootstrapped in `main.py`, which registers CORS middleware, mounts static files, wires global exception handlers from `app/core/error_handlers.py`, and includes per-domain routers (`factory`, `machine`, `production_order`, `tariff`, `meter_reading`, `dashboard`, `optimization`, `auth`, `users`, `alert`). Each domain follows a consistent layered split: `app/models/<domain>.py` declares SQLAlchemy ORM entities inheriting from `Base` in `app/core/database.py`; `app/schemas/<domain>.py` defines Pydantic v2 request/response models; `app/api/<domain>.py` exposes `APIRouter` endpoints that depend on `get_db` (a session generator) and on auth dependencies (`require_role`, `get_current_user`) from `app/api/auth.py`. Business logic is extracted into `app/services/` (e.g. `AuthService`, `cost_calculator`, `optimizer`, `alert_service`) so API handlers stay thin. Configuration is centralized via `pydantic_settings.BaseSettings` in `app/core/config.py` with `.env` support, and database selection (MySQL vs SQLite fallback) is handled in `app/core/database.py`. A separate `seed.py` script populates initial data, and Dockerfile + `.dockerignore` provide containerization.
