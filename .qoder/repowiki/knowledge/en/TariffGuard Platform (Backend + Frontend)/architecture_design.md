The root level wires two sibling services — `backend/` (FastAPI + SQLAlchemy) and `frontend/` (Next.js App Router) — around a single MySQL 8.0 instance defined in `docker-compose.yml`. The compose file defines a `tariffguard_network`, mounts the backend source for hot reload, and starts the uvicorn server on port 8000 with the DB URL pointing to the `db` service; the frontend is served through the backend's `/dashboard` route as documented in README.md. Cross-child contract is the REST API surface under `/api/*` (auth, factories, machines, orders, tariffs, meter-readings, dashboard, optimize, reports, alerts), which the frontend consumes directly; `FRONTEND_BACKEND_MAPPING.md` documents the page-to-endpoint mapping and explicitly marks endpoints still missing from the backend that the frontend must mock. Environment configuration flows from `.env.example` into both services, and demo data is seeded via `docker-compose exec backend python seed.py` after `docker-compose up -d --build`.
